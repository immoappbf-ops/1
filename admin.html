Comment les annonces sont-elles stockées ?

Le site et cette page utilisent la clé locale 42services_real_properties. Les données sont accessibles uniquement dans le navigateur et le profil de navigateur où elles ont été enregistrées. Elles ne sont pas envoyées à GitHub ni partagées automatiquement avec les clients.

Étape Supabase

Ensuite, nous relierons cette page à une base de données en ligne et mettrons en place une authentification administrateur. C’est nécessaire avant de considérer l’interface comme sécurisée ou de publier des annonces réelles pour tous les visiteurs.
